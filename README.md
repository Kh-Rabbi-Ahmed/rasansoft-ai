# Rasansoft Marketing Website

Production-ready marketing website for **Rasansoft** built with **Next.js App Router**, **TypeScript**, and **Tailwind CSS**.

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Build for production

```bash
npm run build
npm run start
```

## Customize content and styles

- **Homepage sections** are composed in `/app/page.tsx` using components in `/components`.
- **Careers page** is in `/app/careers/page.tsx`.
- **Brand colors** and global behavior (including smooth scrolling) are in `/app/globals.css`.
- **SEO metadata** is in `/app/layout.tsx`.
- Placeholder data and links are clearly marked with `PLACEHOLDER` comments for quick replacement.
